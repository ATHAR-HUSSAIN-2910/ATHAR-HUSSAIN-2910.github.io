about_me

I'm an aspiring Data Scientist & AI Engineer with a strong foundation in Machine Learning, Deep Learning, Python, SQL, and Data Analytics. My journey started with data analysis — cleaning messy datasets, validating business rules, and extracting actionable insights from real-world data. Today, I've built 11 end-to-end projects spanning predictive modeling, customer analytics, deep learning, computer vision, RAG systems, database design, business intelligence, and stateful AI agents.

I've implemented and compared multiple ML algorithms including Linear Regression, Logistic Regression, Decision Trees, Random Forest, AdaBoost, Gradient Boosting, XGBoost, and K-Means Clustering. I understand the importance of feature engineering, scaling, encoding, hyperparameter tuning, and model evaluation using metrics like R², MAE, RMSE, Accuracy, Precision, Recall, F1-Score, and ROC-AUC.

I've expanded my deep learning expertise with PyTorch, building Artificial Neural Networks (ANNs) for tabular data and Convolutional Neural Networks (CNNs) for image classification. I use Optuna for hyperparameter optimization, implement early stopping, and apply data augmentation to improve model generalization. I've also built a Retrieval-Augmented Generation (RAG) system using FAISS vector search, Sentence Transformers, and Groq LLM for conversational question-answering over custom knowledge bases. More recently, I've moved beyond single-shot RAG into stateful agentic workflows with LangGraph and LangChain — where an LLM classifies intent, conditional routing decides between RAG retrieval, database tools, or human escalation, and business rules live in Python rather than in prompts.

My flagship project is ShopAssist AI — a LangGraph-powered customer support agent that combines LLM intent classification, RAG over company policies, PostgreSQL order tools, persistent conversation memory via LangGraph's PostgreSQL checkpointer, and a confirmation flow for destructive actions like order cancellation. It ships with a 28-case evaluation suite achieving a 100% pass rate across routing accuracy, response correctness, context-leakage prevention, multi-turn memory, and escalation behavior — reinforcing my belief that an LLM is just one component inside a larger, well-engineered system. Other key projects include a Machine Learning RAG Assistant with conversational follow-up support, Diabetes Prediction using PyTorch ANN with Optuna optimization, CIFAR-10 Image Classification with a custom CNN architecture, Customer Churn Prediction with SHAP explainability, and Customer Segmentation using K-Means clustering. I've also built Streamlit applications to deploy ML models and make them accessible to end users.

Currently, I'm expanding my knowledge into Large Language Models (LLMs), agentic workflows with LangGraph and LangChain, Retrieval-Augmented Generation (RAG), and Model Fine-tuning. My goal is to evolve from a Data Scientist into a well-rounded AI Engineer who can build production-grade AI systems — from data pipelines to stateful, tool-augmented agents and deployed applications.

I believe in the power of AI to solve real-world problems, and I'm excited to bridge the gap between cutting-edge research and practical business applications. When I'm not coding, I'm exploring new datasets, reading research papers, or contributing to open-source projects.
